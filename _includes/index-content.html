Doom RPG Remake Project (DRRP)

{% if page.lang == 'en' %}

This project brings the Doom RPG game from a mobile platform to the GZDoom engine.

The original atmosphere is beautifully intertwined with the latest features of the most modern Doom-ports.

Detailed levels, RPG-leveling system, many dialogs in two languages - all of this in the DRRP project.

{% elsif page.lang == 'ru' %}

Проект DRRP переносит игру Doom RPG с мобильной платформы на движок GZDoom.

Оригинальная атмосфера красиво переплетается с новейшими возможностями современнейших Doom-портов.

Детализированные уровни, система RPG-прокачки, множество диалогов на двух языках - всё это в проекте DRRP.

{% elsif page.lang == 'uk' %}

Проект DRRP переносить гру Doom RPG з мобільної платформи на GZDoom.

Оригінальна атмосфера гарно переплітається з новітніми можливостями сучасних Doom-портів.

Деталізовані рівні, система RPG-прокачки, безліч діалогів двома мовами - все це в проекті DRRP.
